# Release v0.0.1 / 27953f8b

- OTA publication: #35 (`ti-am62x/am62x-sd-ab-v1`).
- Adds resumable HTTP Range downloads. Device staging files live under `.download-<publication>` in the fwctld cache; completed files are SHA256-verified before promotion to the cache and installation.
- The AM625 image defaults to `/data/fwctld`; if `/data` is unavailable, fwctld logs a warning and falls back to `/tmp/fwctld` so OTA remains available.
- Physical device booted deployment 0, slot A, and passed initramfs rootfs SHA256/dm-verity verification and the regular health confirmation. OTA server recorded `success` for boot ID `9083f25d-298a-4ecd-8351-7371ff9ba126`.
- The board's `/data` partition was not writable during validation, so this run did not verify retaining a partial download across power loss. A writable persistent data filesystem is required for that scenario.
- The OTA files were transferred and installed successfully. An intermediate fwctld build had an exact-size check bug for the small `latest` manifest; the final release fixes it. Publication #35 was staged with `fwctl update` after the intermediate daemon could not poll, then the new daemon reported the health-confirmed boot.
