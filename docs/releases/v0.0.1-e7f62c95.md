# v0.0.1 / e7f62c95

Automatic installation now owns a local durable transaction and ordered report
queue, independent of the download cache and of management-server availability.
Each phase is saved with the full firmware identity, a monotonic sequence and
CRC-protected framing. Immutable events are synchronized before the transaction
snapshot; replay checks the server publication's full identity before sending.
Acknowledged events are removed only after a durable snapshot is retained.

The device reconciles boot confirmation and rollback before the network gate.
After a verified write, reboot follows the durable local commit without waiting
for an HTTP acknowledgement. New writes require a working journal; unavailable
or corrupt state preserves evidence and defers installation. A service stop is
recorded as cancellation rather than a firmware incident. Policy and the active
publication are checked again immediately before writing.

Validation: local-journal crash/fsync/corruption/queue-limit tests, 35 automatic
upgrade cases, 12 init-script cases, network/quarantine/history/context/shutdown
checks, four real FIT tests and actual AArch64 initramfs loading.
