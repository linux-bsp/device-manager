# v0.0.1 / fd821f46

OTA, firmware URL sources, initramfs/background recovery, SOL append uploads and
clock HTTP requests now use the shared C transfer component. Server request/body
handling and firmware/archive file downloads use its HTTP server primitives.
Business modules no longer invoke curl or sha256sum or duplicate direct libcurl
code. No transfer executable, daemon or network service was added.

The component provides bounded streaming I/O, explicit timeouts/cancellation,
opt-in GET retries, HTTP Range and SHA256-bound durable checkpoints. Data is
flushed before checkpoint commit; restart rehashes the prefix and truncates only
uncommitted tail bytes. Network, storage, integrity and protocol errors remain
separate. POST is not automatically replayed. SOL keeps its archive commit ACK
and only then clears startup RAM banks; serial payload bytes are unchanged.
Initramfs includes fwctl's ELF dependencies without a curl executable.

Validation: 17 real transport tests (HTTP/TFTP, process kill/reopen, corrupt
checkpoint/prefix, Range, bounded responses, cursor correction and injected
flush failures); 211 OTA Python cases plus 22 browser cases; 21 logging/time
cases; eight native firmware groups; two storage-sync groups; six recovery
cases; four FIT cases; actual AArch64 loader execution; Linux/U-Boot identity
interoperability; eight CLI cases with the actual firmware package.

`1010001000110000`, after reboot and health confirmation. Full firmware ID:
`fd821f46f43a69d4e5d075d5cd7f88dc8022387a6fff197d2d3c8413934b33b6`.
